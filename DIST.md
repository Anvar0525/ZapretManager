# Как раздавать без Python

## Для вас (сборка)
1. Запустите `build_exe.bat`
2. Готовый файл: `dist\ZapretManager.exe`

## Для других пользователей
1. Скачать **ZapretManager.exe**
2. Положить рядом с папками `zapret-discord-youtube-*`  
   Например:
   ```
   C:\Zapret\
     ZapretManager.exe
     zapret-discord-youtube-1.10.0\
   ```
3. Запустить exe → подтвердить UAC
4. Python **не нужен**

Обновления самого zapret (Flowseal) менеджер качает сам в эту же папку.
